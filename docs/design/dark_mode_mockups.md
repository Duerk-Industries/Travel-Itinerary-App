# Dark Mode Screen Mockups (Reference)

These PNG mockups are **layout references** for implementation. They define:
- hierarchy
- spacing
- component composition
- color role usage

## Included mockups
- `mock_dark_itinerary.png`
- `mock_dark_follow_trip.png`
- `mock_dark_activity_feed.png`

## Implementation notes
- Use the same component primitives as light mode: cards, chips, list items, buttons.
- Replace light surfaces with:
  - bg: `#0B1726`
  - surface: `#1C2B3A`
  - card: `#243647`
  - text: `#E6ECEF`
- Use accent colors sparingly in dark mode; prefer them as **left bars**, **icons**, and **CTA buttons**.
