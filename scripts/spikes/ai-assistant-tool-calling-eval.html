AI Trip Assistant — tool-calling eval

Phase 0 spike harness for docs/implementation_plans/implementation-plan-ai-assistant.md. Runs a fixed set of realistic action prompts against an on-device WebLLM model with the app's candidate tool schemas, and grades whether the model picked the right tool with the right arguments. Needs a WebGPU-capable browser (Chrome/Edge desktop). Don't open this file directly (file://) — serve it locally first, e.g. from the repo root: npx serve scripts/spikes, then open the printed http://localhost:... URL. Model weights are fetched directly from Hugging Face by WebLLM — nothing here talks to any app/server backend.
